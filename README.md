# Crystal UV Stickers — Overseas Landing Page

英文单页落地页：水晶标（Crystal UV Stickers），**同一站服务 B2C + B2B**。

- B2C：WhatsApp 看图 / 定制
- B2B：询盘表（数量、目的国、规格）——**不公开单价**

## 本地预览

用任意静态服务器打开目录，例如：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 替换联系方式

编辑 `config.js`：

```js
whatsappE164: "8613800138000", // 仅数字，含国家码
email: "you@domain.com",
```

保存后刷新页面即可。
